# Big Planetarium Website

This is a rebuilt accessible three-page website prototype for the Big Planetarium web development assessment.

## Pages

- `index.html` - Milky Way landing page with a hero image and interactive orbit canvas.
- `planets.html` - interactive atlas for all eight planets.
- `mars.html` - dedicated Mars page with facts and a quiz.

## How to Open

Open `index.html` in a browser, then use the navigation links to move between pages.
